# Past release notes

The long-form notes for each release, as published with it.

`RELEASE_NOTES.md` in the repository root is always the **current** release.
When a new one is written, the outgoing file moves here as `v<version>.md`.

They accumulated at the root before that — `RELEASE_NOTES_v2.11.0.md` beside
`RELEASE_NOTES_v3.0.0.md` beside `README.md` — which is a directory listing that
gets one line longer every release.

`docs/Changes.md` is the other half of this and is not the same thing: it is the
running changelog across every version, and it is what `release.ps1` publishes
as the body of the GitHub release. These files are the essay; that one is the
record.
